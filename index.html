Payment submit karo / check karo

Auto check kya check karta hai: (1) TRX ID khali to nahi, (2) Amount Rs 50 hai ya nahi, (3) Ye TRX ID pehle to use nahi hui (duplicate = fake), (4) TRX ID kam se kam 8 characters ki hai ya nahi.
Sachai: Ye auto check EasyPaisa ke bank account se TRX ID ko verify NAHI kar sakta — bank ka record sirf EasyPaisa account statement mein dikhta hai. Is liye Accept yahan provisional hai: auto rules pass hone par connection unlock ho jata hai, lekin final paisa confirm karne ke liye admin ko EasyPaisa account mein transaction dekhna chahiye. Agar statement mein paisa nahi mila, to us TRX ID ko Reject karke block kar do.

Accept par kya hoga / Reject par kya hoga

  • Accept: Us user ka connection unlock ho jata hai — wo chat/group shuru kar sakta hai, us ka package active ho jata hai, aur doosri taraf ka jawab FREE ho jata hai.
  • Reject: Connection LOCKED rehta hai — user chat nahi kar sakta, usay dobara sahi TRX ID ke saath pay karna parega, aur ye TRX ID dobara use nahi ho sakti (duplicate = reject).
  • Block (sham ko check ke baad): Auto accept ke baad bhi agar EasyPaisa statement mein paisa na mile, to Block dabao — us bande ka connection lock ho jata hai, wo dobara us TRX ID se chat nahi kar sakta, aur usay naye TRX ID ke saath dobara pay karna parega.
